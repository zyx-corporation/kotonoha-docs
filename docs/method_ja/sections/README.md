# Kotonoha Method セクション構成

Status: draft / non-normative

このディレクトリは、Kotonoha Method を HTML / JavaScript / SVG 表現へ発展させるためのセクション単位の構成を管理する。

長い章本文は、Markdown草稿として維持しつつ、読者向け公開・教材化・図表化の段階で、より小さなセクションへ分割する。

---

## 方針

- 章本文は `docs/method_ja/chapter_*.md` に残す。
- セクション単位の公開構成はこのディレクトリに置く。
- 図表は `docs/method_ja/assets/svg/` に置く。
- HTML版は `docs/method_ja/method_site/` に置く。
- インタラクティブ表現を推奨するが、印刷/PDF用の静的代替を常に保持する。

## 図表対応方針

各セクションは、可能な限り次のいずれかの図表を持つ。

| 図表種別 | 目的 |
| --- | --- |
| flow | 意味変化の流れを示す。 |
| layers | SLS / RDE / Method / Console の層構造を示す。 |
| comparison | 従来PMとKotonoha Methodの差を示す。 |
| state-machine | AI生成物や文書状態の遷移を示す。 |
| responsibility | 分散した責任が再収束する構造を示す。 |

各SVGには、印刷用の静的説明を本文またはキャプションとして用意する。
