# Tutorials

Tutorials are step-by-step guides for **learning** Kotonoha-related workflows.

They are not acceptance checklists. A tutorial should explain why each step matters, what the reader is expected to learn, and where to go next. Tutorials may simplify details; always cite **`kotonoha-spec`** when readers need exact semantics.

For procedural validation and release-facing checks, use [Acceptance demos](../acceptance/README.md).

**Japanese:** [../tutorials_ja/README.md](../tutorials_ja/README.md) (all Japanese tutorial pages live under `docs/tutorials_ja/`)
