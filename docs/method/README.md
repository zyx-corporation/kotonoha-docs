# Method — building Kotonoha with SLS + RDE

This section describes **how the Kotonoha project applies Semantic Lineage System (SLS) thinking and Resonant Deviation Evaluator (RDE)–style review** to its own engineering and documentation work. It is **non-normative**: it does not define interoperable APIs or schemas (those belong in [`kotonoha-spec`](https://github.com/zyx-corporation/kotonoha-spec)).
