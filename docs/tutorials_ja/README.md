# チュートリアル（日本語）

チュートリアルは、Kotonoha 関連ワークフローを**学ぶ**ための段階的なガイドです。

これは受入チェックリストではありません。チュートリアルでは、各手順をなぜ行うのか、読者が何を理解すべきか、次にどこへ進むべきかを説明します。細部は簡略化されている場合があります。厳密な意味内容は必ず **`kotonoha-spec`** を参照してください。

手順検証やリリース確認に近い資料は [受入デモ](../acceptance_ja/README.md) を参照してください。
