# Paper — academic and long-form artifacts

This directory holds **peer-reviewed papers, preprints, and other long-form academic writing** related to Kotonoha / SLS when the maintainers choose to publish them alongside this documentation repository.

- This material is **not normative** for implementers. Canonical technical definitions remain in [`kotonoha-spec`](https://github.com/zyx-corporation/kotonoha-spec).
- Each file added here should declare **license and provenance** in the same change (or in the document front matter) so readers know redistribution terms.
- Prefer **Issue-driven additions**: open or reference an Issue before adding PDFs or large binary assets.

Tracking issue for introducing this section: [kotonoha-docs#31](https://github.com/zyx-corporation/kotonoha-docs/issues/31).
