Kotone 概念図

KMCS 上に Kotonoha / SLM / データベース / Sensor入力処理 / Audio I/O / 通信機能 / Home Assistant を併置し、 各モジュールは KMCS Bus を介して必要に応じて相互接続される構成

この版では、Home Assistant と Audio I/O を左側へ、データベース を右側へ移動しました。 外部の Sensor I/O Devices は Home Assistant および Sensor入力処理 と接続し、 外部の Audio I/O Devices は Audio I/O モジュールと接続しています。 KMCS 内部は point-to-point 接続ではなく、KMCS Bus を介する構造です。
