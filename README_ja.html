kotonoha-docs（日本語概要）

Semantic Lineage System（SLS）の仕様に含まれない、利用者・コミュニティ向けの公開ドキュメントを置くリポジトリです。

English / Markdown source

概要

仕様の正本・規範的な定義は kotonoha-spec にあります。本リポジトリは、マニュアル、チュートリアル、ハウツー、受入デモ、補助的な説明など、normative ではない公開文書を対象とします。

置くもの／置かないもの

置くもの

  • 利用・運用のマニュアル（docs/manual/）
  • 学習用チュートリアル（docs/tutorials_ja/）
  • 受入デモなど、仕様外の確認手順（docs/acceptance_ja/）
  • FAQ、移行メモ、ハウツー、補助的な説明
  • 開発手法の説明（例: docs/method_ja/）
  • 本リポジトリへの貢献手順（CONTRIBUTING）

置かないもの

  • 実装者向けの規範仕様・スキーマ・安定インターフェースの定義。仕様の正本は kotonoha-spec に置きます。
  • 非公開の計画・草案。この公開サイトでは書かず、提携コントリビューターへはメンテナ側のチャネルで個別に案内があります。
